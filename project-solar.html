REC-005 — Applied Machine Learning

AI-Driven Solar Panel Tracking Model

Fixed-tilt solar installations lose energy whenever they're not pointed straight at the sun. I built a Python model to predict the optimal dual-axis position and measured how accurately it could track.

Type
Personal / research project
Stack
Python · Machine Learning
Accuracy
84% dual-axis alignment (simulated)
Date
Aug 2025
Problem

Fixed-tilt panels leave energy on the table.

Solar irradiance moves throughout the day, but most low-cost installations use a fixed panel angle. That mismatch between panel position and sun position is a direct, measurable energy loss.

Approach

Simulate the sensor inputs, train the model to track the sun.

I built a Python machine learning model that processes dynamic irradiance and simulated sensor inputs, standing in for the data a physical dual-axis tracker would read, and outputs the optimal panel angle on both axes as conditions change.

Result

84% positioning accuracy, in simulated environments.

The model achieved 84% dual-axis positioning alignment accuracy in simulated environments — evidence that a relatively lightweight model can meaningfully track optimal panel position, though this result reflects simulation, not a deployed physical tracker.
